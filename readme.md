# SchweizMobil route scraper

Collects route information from [schweizmobil.ch](https://schweizmobil.ch) for five activity types
(Wanderland, Veloland, Mountainbikeland, Skatingland, Kanuland).

## Setup

```
pip install -r requirements.txt
playwright install chromium
```

## Project Structure

### Scraping Process
The scraping process is modularized:
- `config.py`: Configuration parameters, overview pages, selectors, and constants.
- `parsers.py`: Pure helper and text-parsing functions (regex, string cleaning, stage parsing).
- `scraper.py`: Playwright-based browser automation, link collection, and route scraping logic.
- `main.py`: Entry point, command-line interface (CLI), run orchestration, and CSV output.

Options for main:  `--lands` (one or more lands), `--limit N` (max. routes per overview, for testing),
`--show` (show the browser window), `--inspect` (no scraping, only print the page structure),
`--resume` (keep the rows already in the result file and scrape only the routes that are missing).

The scraping process generates the file schweizmobil_routen.csv containing the raw data collected from the website.

### Assigning Cantons
`canton_assignment.py` matches each route from schweizmobil_routen.csv to a canton using geodata. 
This process generates the file routes_cantons.csv. 

### Data processing for each research question
Each research question has specific requirements for data processing.  
- `rq1.py`: filtering routes below 1200 m above sea level, calculating route density
- `rq2.py`: counting the number of routes per difficulty level
- `rp3.py`: calculating the route density per activity, calculating evenness across activities, creating categories
These processes generate individual csv files containing only the relevant information for each research question (indicated by the prefix of the respective research question). 

### Visualizations
Each visualization is generated by a separate script in `visualization`. The results are stored in `plots`. 


## Known limitations/assumptions
- Regional routes: `duration_min` is empty (the page shows no total duration); the stage lengths in
  `etappen_detail` were not verified on all lands.
- The difficulty ratings of Mountainbikeland and Skatingland are based on the icons and are assumed to be in the order technical, condition.
- Pages with an unexpected structure produce a warning and leave the elevation columns empty.
